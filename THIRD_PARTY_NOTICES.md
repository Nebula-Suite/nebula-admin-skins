# Third-party notices

Nebula Admin Skins ships JSON skin files only. No JavaScript, CSS, fonts, icons or images are bundled, and the Composer dependencies are installed by Composer with their own licence files. Two skins take their colour values from published palettes, listed below.

## Which skin contains what

| Project | Licence | Used in |
|---|---|---|
| Dracula theme palette | MIT | `view/adminhtml/nebula/skin/dracula.json` |
| Nord palette | MIT | `view/adminhtml/nebula/skin/nord.json` |

The colour values are the published palettes, mapped onto Nebula's colour tokens. Four skins nudge a primary button fill so the label clears 4.5:1 (see the README); the rest of each palette is unchanged.
